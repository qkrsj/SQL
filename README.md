# sql-daily

SQL 기초부터 매일 한 파일씩 연습하는 저장소입니다.

## 진행 방식
- 파일명: `dayNN_주제.sql`
- 각 파일에 개념 설명(주석), 예제 쿼리, 연습 문제 포함

## 커리큘럼
| Day | 주제 |
|-----|------|
| 01 | SELECT 기초 (완료) |
| 02 | WHERE 조건 (완료) |
| 03 | ORDER BY, LIMIT (완료) |
| 04 | 집계 함수 (COUNT, SUM, AVG) (완료) |
| 05 | GROUP BY, HAVING (완료) |
| 06 | INNER JOIN (완료) |
| 07 | LEFT / RIGHT JOIN (완료) |
| 08 | 서브쿼리 (완료) |
| 09 | INSERT / UPDATE / DELETE (완료) |
| 10 | CREATE TABLE, 제약조건 (완료) |
